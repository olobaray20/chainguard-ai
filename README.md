
# ChainGuard AI 🛡️

AI-powered on-chain intelligence miner built for the Telegraph Hackathon.

## Overview

ChainGuard AI analyzes blockchain wallet activity and transforms raw on-chain data into actionable risk intelligence.

It helps AI agents and users understand wallet behavior through:
- Risk scoring
- Wallet activity analysis
- Suspicious activity detection
- Evidence-backed explanations

## How It Works

Wallet Address
↓
Blockchain Data Collection
↓
Risk Analysis Engine
↓
AI Intelligence Layer
↓
Risk Report
